# 生信四年作战手册

> AI 驱动的生物信息学学习管理桌面应用，专为大一到保研/考研的四年规划而设计。

## 简介

这是一个面向生物信息学专业本科生的智能学习管家应用。从大一开始积累 GPA、错题、技能树、科研经历、竞赛记录，AI 全自动排程、复习追踪、风险预测，帮你四年保持竞争力。

## 技术栈

- **桌面框架**: Tauri 2 (Rust 后端 + WebView 前端)
- **前端**: 原生 HTML / CSS / JavaScript（无前端框架，单文件架构）
- **AI 集成**: 8 个大模型 API 轮询 + 场景路由
  - 百炼 qwen-plus（通用主力）
  - DeepSeek-V4（代码 / 数学推理）
  - 豆包 Doubao（论文阅读）
  - Kimi K3（1M 上下文长论文）
  - MiniMax M3（Agent 排程备用）
  - 智谱 GLM-5.3（编程）
  - 硅基 Qwen2.5（备用）
  - qwen-vl-plus（图片 OCR）
- **构建工具**: Vite 6 + 自定义 copy-build.js（支持热更新）
- **主题**: 浅色白卡片风格 + 生信红品牌色（`#c81d4e`），统一白底黑字保证可读性

## 核心功能

### AI 智能引擎
- **多模型轮询**: 8 个 AI 模型按场景自动路由（代码→DeepSeek，论文→Kimi，排程→百炼）
- **持久记忆**: 跨会话记住你的对话历史和学习偏好
- **RAG 知识检索**: 本地知识库增强 AI 回答准确性
- **多步推理链**: 复杂问题自动展开推理过程
- **多模型共识校验**: 重要问题交叉验证多模型答案
- **AI 自我纠错**: 回答后自动评估质量，低分自动修正

### AI 主动代理
- **全自动学习教练**: 晨间→午间→下午→晚间→周度，AI 自主驱动学习闭环
- **上下文感知**: 检测停留时间、发呆、反复访问，主动提供帮助
- **跨模块推理**: 错题→教材→技能树自动关联推荐
- **苏格拉底追问**: 不直接给答案，5 层递进追问引导思考
- **预测引擎**: 完成率下降→预测摆烂，错题增速→预测考试丢分
- **动态知识引擎**: AI 实时生成微课和练习，按水平调整难度

### 自动化闭环
- **遗忘曲线追踪**: 基于艾宾浩斯曲线，在最快要忘的时候推送复习
- **知识盲点自动捕获**: AI 对话中自动识别知识缺口
- **技能掌握度自动更新**: 根据任务完成和错题数据自动调整
- **练习自动评分**: AI 生成练习→用户答题→AI 评分→更新记忆强度
- **任务智能调度**: 逾期自动拆分，低完成率自动减负

### 管家功能
- **自然语言指令**: "添加错题"、"生成Python微课"、"推迟任务"——直接执行
- **晨间 AI 简报**: 每天首次打开，30 秒掌握全局
- **情境感知推荐**: 知道你在哪个页面，主动提供最相关的操作

### 学习管理
- **今日任务**: AI 排程 + 番茄钟 + 专注模式
- **错题本**: 拍照粘贴 + AI OCR + 自动分类
- **技能树**: 四年技能地图，从 Python 到生信全栈
- **GPA 管理器**: 成绩录入 + 趋势线 + 保研预测
- **学习债务池**: 欠下的学习任务，逾期自动追踪
- **四年规划**: 学期计划 + 夏令营 + 导师情报 + 科研项目

### 数据可视化
- **AI 全息学习画像**: 学习风格、最佳时段、知识盲区、动机趋势
- **学习数据大屏**: 掌握度热力图、周趋势线、错题分布饼图、平衡度周历
- **四年进度模拟器**: AI 预测你在大三夏令营时的 GPA / 技能水平

### 生活平衡
- **休息提醒**: 学习 50 分钟自动提醒休息
- **平衡度评分**: 学习 vs 休息 vs 娱乐的健康度
- **过劳保护**: 连续超时自动强制建议放下

## 快速开始

### 环境要求
- Node.js 18+
- Rust 1.70+
- Tauri CLI 2.x

### 构建
```bash
npm install
node copy-build.js      # 构建前端到 dist/
cd src-tauri
cargo build --release   # 编译桌面应用
```

### 配置 AI
打开应用 → 数据管理 → 填入至少一个 AI 模型的 API Key（推荐百炼 qwen-plus，有免费额度）

## 项目结构
```
├── src/
│   └── index.html          # 单体应用（HTML + CSS + JS）
├── src-tauri/
│   ├── src/main.rs          # Tauri 后端
│   ├── Cargo.toml           # Rust 依赖
│   ├── capabilities/        # 权限声明
│   └── resources/web/       # 打包资源
├── copy-build.js            # 构建脚本（自动备份 + 部署）
└── dist/                    # 构建输出
```
